# Proposal

## Why

当前工具只能对单张图片检测。实拍硬币和盘子往往以视频形式连续出现，逐帧截图再检测既费时，也丢失时间顺序。需要在现有 GUI 上直接导入视频，按当前参数逐帧检测，便于回放定位和导出关键帧。

## What Changes

- 新增视频文件导入，至少支持 OpenCV 能解码的 MP4、AVI；MOV 等格式按本机解码器能力提供并明确提示。
- 导入后显示首帧、分辨率、帧率与总帧数；元数据缺失时显示未知，不阻断播放。
- 新增播放、暂停、停止、上一帧、下一帧和进度定位。
- 播放或单步时对当前帧执行现有霍夫圆检测，叠加圆、圆心与编号，并显示本帧圆数量。
- 六个检测参数对视频生效；调参后经短暂防抖（不超过 150 ms）重检当前帧，后续帧使用新参数。
- 支持把当前标注帧导出为 PNG/JPG，尺寸与视频帧一致。
- 视频无法解码、读取失败或到达结尾时给出明确状态，不崩溃；关闭或替换视频时释放解码资源。
- 非目标：不导出整段标注视频、不做跨帧跟踪或平滑、不接入实时相机、不处理音频、不引入 GPU 加速。

## Capabilities

### New Capabilities

- `video-detection`: 视频文件导入、播放与定位、逐帧霍夫圆检测、当前标注帧导出和错误处理。

### Modified Capabilities

无。现有 `hough-circle-gui` 的图片导入、调参、预览与导出行为保持不变；视频作为独立能力叠加。

## Impact

- 新增 `hough_circle_gui/video.py`，封装 `cv2.VideoCapture` 与视频元数据，不依赖 Tkinter。
- 扩展 `hough_circle_gui/app.py` 的界面状态、播放循环、参数联动和导出入口。
- 复用 `detector.py`、`presets.py` 和现有图片导出逻辑。
- 不新增第三方依赖；需要短视频样例及来源记录，大文件不入库。
- 编码器兼容性、播放流畅度和定位精度依赖目标机器的 OpenCV/FFmpeg 构建，需在实现阶段实测。
